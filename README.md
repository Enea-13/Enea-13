### Enea Malaj

Senior full-stack engineer for data-heavy web apps: React and Next.js on the front, GraphQL, .NET and SQL Server behind. Seven years of production work for YOOX Net-a-Porter, INPS and Investire SGR.

My client work lives in private repositories. In public:

- **[keres-endings](https://github.com/Enea-13/keres-endings)**: a Python pipeline that recognises the 879 diagrams in a chess-endings book and links 98.5% of its 17,855 printed moves to board positions, behind a React study app. [Demo](https://enea-13.github.io/keres-endings/)
- **[talking-back](https://github.com/Enea-13/talking-back)**: a phone-first app that answers difficult thoughts with Bible verses. It works offline, installs from the browser, has iOS and Android builds through Capacitor, and plays recorded verses that highlight word by word. [Demo](https://talking-back.vercel.app)
