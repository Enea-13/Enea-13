### Enea Malaj

Senior full-stack engineer for data-heavy web apps: React and Next.js on the front, GraphQL, .NET and SQL Server behind. Seven years of production work for YOOX Net-a-Porter, INPS and Investire SGR.

Client work lives in private repositories. The best public example is [keres-endings](https://github.com/Enea-13/keres-endings): a Python pipeline that recognises the 879 diagrams in a chess-endings book and links 98.5% of its printed moves to positions, behind a React study app ([demo](https://enea-13.github.io/keres-endings/)).

Case studies and CV: [eneamalaj.com](https://eneamalaj.com) · hello@eneamalaj.com
